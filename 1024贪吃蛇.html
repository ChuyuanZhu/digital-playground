玩法规则详细说明

1. 标准模式 (Standard)

• 初始值 1024。吃比自己大的数相乘，吃比自己小或相等的数相除。
• 误吃非 2 的指数或数值被除到 < 1 时游戏结束。

2. 简单模式 (Simple / 纯加减法)

• 初始值 1。全场无死穴陷阱。
• 吃到比自己大的数两数相加，吃比自己小的数两数相减。数值 ≤ 0 死亡。

3. 自定义模式 (Custom)

• 自主输入任何 ≥ 2 的正整数，规则完全继承标准模式。

4. 赌博模式 (Gamble)

• 初始值 1。
• 新手保护：开局吃到的第一个方块必定为加法 (+)，拿到第一桶金！
• 博弈分级：
  - 绿色方格（稳健小注）：数值很小，即使输了也扣得起，适合稳扎稳打。
  - 高亮红色方格（高额大注）：数值巨大，赢了资产翻番，输了直接破产！
• 吃掉方块后伴随 + / - 动态飘字反馈。数值 ≤ 0 游戏结束。
